# dsh-open-path

**简体中文** · [English](README.md)

一个 `/open` 斜杠命令：用平台默认程序打开文件、文件夹、http(s) 链接或裸域名，并在工作区里模糊查找目标。显示在 [dsh-TUI](https://github.com/ccch1mneyyy/dsh-TUI) 里。

## 用法

```sh
/open                          # 打开当前会话的工作目录
/open <路径>                   # 绝对或相对路径（必须存在）
/open https://example.com      # 用默认浏览器/处理器打开
/open github.com               # 裸域名：自动补 https://（localhost/IPv4 用 http://）
/open ~/docs                   # 开头的 ~ 展开为用户主目录
/open <片段>                   # 在工作区里模糊查找：命中 1 个直接打开，多个弹选择框
```

**信任边界**：只有 `http` / `https` 链接会交给操作系统处理器；其他协议（`file:`、`javascript:`、`ftp:`、`ws:` …）一律拒绝并给出明确错误，不会落到路径或模糊查找分支。

## 语言

命令回执、错误提示、候选项与命令提示都跟随宿主语言，解析链与 dsh-TUI 自身一致：

`DSH_TUI_LANG` → 运行中的 `dsh-tui` 设置命名空间（`/lang` 的落点）→ `~/.dsh-tui/lang.json` → 系统 locale → 中文。

- 语言**存在但不支持**（例如 fr）时回落英文；**完全没有信息**时沿用中文，保证中文宿主的行为与加入双语之前逐字一致。
- 回执在每次调用时重新解析语言，所以 `/lang` 切换**无需重启**；命令补全里的提示文字是注册时的快照，重启后跟随新语言。
- `DSH_OPEN_PATH_LANG_FILE` 可覆盖偏好文件路径（测试与诊断用）。

## 设置

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| Max candidates / 候选上限 | number | `0` | 模糊查找最多向选择框提供多少候选项；`0` 表示不设上限（交给宿主自己的上限）。 |
| Include hidden / 包含隐藏项 | boolean | `false` | 工作区索引是否包含隐藏文件与目录。 |

设置卡片与命令描述均为中英双语；宿主按当前语言渲染。

## 已知限制

- 目标必须存在（URL 除外）：路径不存在时不会“创建后打开”，而是报错或转入模糊查找。
- 无图形会话的环境（纯 SSH、容器、无 DISPLAY）会明确报错，而不是静默失败。
- 成功打开以“启动器进程成功执行为准”：某些桌面环境会把请求转交后立刻返回，因此“已打开”不保证窗口已获焦点。
- 候选项很多且宿主没有选择框接缝时，只列出前若干项并提示键入更精确的路径。

## 开发与验证

TypeScript 工程：源码在 `src/`，构建产物在 `lib/`（**不要直接改 `lib/`**）。

```sh
pnpm install
npx tsc -p tsconfig.json     # 构建
npx vitest run               # 单元测试（含双语字典键集与语言解析链）
```
